# Explanation

These pages explain why the library works the way it does. They do not show how to do a task: the
[how-to guides](../how-to/index.md) do that. They do not list parameters: the [reference](../reference/index.md)
does that.

- [How a program reads](program.md): the order of the calls, and why a program reads like the table it makes.
- [The result shape](result-shape.md): the one data set that every statistics macro writes.
- [How a number is kept and printed](numbers.md): the full value, the pattern, the text.
- [One macro, one procedure](design.md): the rules the macros follow, and what they leave out on purpose.
- [What the proof shows](proof.md): how the macros are checked against pharmaverse, and the limits of that check.
