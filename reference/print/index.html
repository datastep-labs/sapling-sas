    %print¶

    Prints a table or a listing with one PROC REPORT into an RTF file and a monospace listing file.

    Procedure: PROC REPORT · Family: Build a table

    Syntax¶

    %print(
     data     =
   , by       =
   , var      =
   , page     =
   , together =
   , label    =
   , rows     = 40
   , file     =
   , nodata   = No data qualified
   , debug    = no
 )

    Parameters¶

    data=
    The rows to print: the display data set of %layout, or the records of a listing. (required)
    by=
    The left columns, printed first: variables separated by blanks. A repeated value is shown once. (optional)
    var=
    The other columns, in the order of the print: variables separated by blanks. A list such as c: or c1-c5 is allowed. (required)
    page=
    A variable: each value starts a new page, and #BYVAL1 in a title prints the value. A variable HEAD_X gives the header of the column X on the page of its row. (optional)
    together=
    A variable: the rows of one value stay on one page, such as together = grp of %layout. (optional)
    label=
    Column labels: name="text" pairs, separated by blanks, such as %STR(row=" "). A | splits a header into lines. When not given, the labels of the variables are used. (optional)
    rows=
    The rows of a page for together=: a positive whole number. (optional, default 40)
    file=
    The output: a path without its extension. The macro writes <file>.rtf and <file>.lst. (required)
    nodata=
    The text printed when there is no row: a text without quotes, as the default (a quote in it is printed). (optional, default No data qualified)
    debug=
    yes: keep the work data sets print. (optional, default no)* Accepts: yes, no.

    Result¶

    The files: <file>.rtf (style journal, landscape) and <file>.lst (the LISTING destination), under the titles and footnotes of the program. With page=: the pages of each value, in the order of the rows.

    Details¶

    It prints a table from its display data set (%layout), and a listing from its records; %table runs %columns, %ard, %layout and %print in one call.

    • The BY columns come first, and a repeated value is shown once. The VAR columns follow: numbers right aligned, text left aligned as written (its leading blanks kept).
    • A text column of var= wider than 40 characters wraps at a width of 40.
    • The header of a column is its pair of label=, else its HEAD_X variable on the page (with page=), else the label of the variable. A | in a header splits it into lines.
    • ODS wraps and pages the RTF. The rows of one value of together= stay on one page of the listing when they fit in rows=; a group that does not fit in what is left of a page starts a new page.
    • A table that is too wide for a page goes on in a second part, and the last BY column is repeated there.
    • With page=, each value of the page variable gets its own pages, in the same two files, under a BY statement, so that a title can name the value (OPTIONS NOBYLINE and TITLE2 "Sex: #BYVAL1").
    • With no row, the report has one row: the text of nodata=.

    The setup of %layout (setup=) holds the parameters of a table: %print(&name.) prints its display data set again after a change. A parameter that is not in the setup is added after it: %print(&name., file=...). SAS stops a call that has a parameter twice: change that parameter in %layout.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read t14_2_1_display (made by the example of %layout), t14_1_1_display (made by the example of %layout). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %describe, %anova, %freq, %chisq, %stack, %columns, %ard, %layout, in this order. Then the examples of this page run as shown.

    /* from the example of %describe */
* Summarizes age in each group and in the Total: n, mean, SD, median, minimum and maximum.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a
   , total = yes
   , label = "Age (years)"
   , out   = age_describe
 )
* Adds sex as a second BY variable: the rows of each group and sex, for a page per sex.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a sex
   , total = yes
   , label = "Age (years)"
   , out   = age_sex
 )
/* from the example of %anova */
* Tests age across the three groups: one row, the p value of the F test.;
%anova(
     data  = adsl
   , var   = age
   , by    = trt01a
   , label = "Age (years)"
   , out   = age_anova
 )
/* from the example of %freq */
* Counts each sex in each group and in the Total: n and the percent of the subjects of the group.;
%freq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , total = yes
   , label = "Sex"
   , out   = sex_freq
 )
* Adds sex as a second BY variable: the age groups of each group and sex, for a page per sex.;
%freq(
     data  = adsl
   , var   = agegr1
   , by    = trt01a sex
   , total = yes
   , label = "Age group"
   , out   = agegr_sex
 )
/* from the example of %chisq */
* Tests sex across the groups: one row, the p value of the chi square test.;
%chisq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , label = "Sex"
   , out   = sex_chisq
 )
/* from the example of %stack */
* Stacks four results in the order of the table: RESULT and ORD tell where each row came from.;
%stack(age_describe age_anova sex_freq sex_chisq, out=t14_2_1)
* Stacks age and the age groups by sex: the results of a table with a page per sex.;
%stack(age_sex agegr_sex, out=t14_1_1)
/* from the example of %columns */
* Makes the four columns with their N from adsl, the Total last, in the order of TRT01AN.;
%columns(
     data  = t14_2_1
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , total = yes
   , out   = t14_2_1_cols
 )
* Gives page=sex: one row per column and sex, the N of each column on the page of its sex.;
%columns(
     data  = t14_1_1
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , page  = sex
   , total = yes
   , out   = t14_1_1_cols
 )
/* from the example of %ard */
* Writes every number of the table and each column N to one CSV file: the raw value and the text.;
%ard(data=t14_2_1, columns=t14_2_1_cols, file=t14_2_1)
/* from the example of %layout */
* Makes the display data set: one row per printed line, one column per group, sex by its labels.;
%layout(
     data    = t14_2_1
   , columns = t14_2_1_cols
   , var     = trt01a
   , format  = sex $sexf.
   , file    = &spl_out./tlf/t14_2_1
   , setup   = t14_2_1_print
   , out     = t14_2_1_display
 )
* Makes one page per sex: SEX and HEAD_C1 to HEAD_C4 hold the page and the N of each column on it.;
%layout(
     data    = t14_1_1
   , columns = t14_1_1_cols
   , var     = trt01a
   , page    = sex
   , format  = sex $sexf.
   , file    = &spl_out./tlf/t14_1_1
   , setup   = t14_1_1_print
   , out     = t14_1_1_display
 )

    Prints the display data set as RTF and as a listing: the rows of one block stay on one page.

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    rows=<rows> is not a positive whole number give rows= the rows of a page, such as 40.

    Proof¶

    Its 18 test cases (each with a clean log and the files it is about) and the tables and listings of a made-up study (12 of 12, also as the code the macros wrote, run without the macros); ran on SAS 9.4 M9, 2026-11-12.

    The known answers and test cases are kept with the development of the library, not in this repository.

    The examples of this page ran on SAS 9.4 M9 on 2026-11-27, with a log free of ERROR and WARNING.

    Used in the proof against pharmaverse: t14_2_01 (R Submission Pilot 1), t14_3_01 (R Submission Pilot 1), t14_3_02 (R Submission Pilot 1), adverse_events (pharmaverse examples), demographic (pharmaverse examples). See what the proof shows.
