    %forestplot¶

    Draws a forest plot of estimates in subgroups as PNG and RTF files and returns the numbers drawn.

    Procedure: PROC SUMMARY, PROC SGPLOT · Family: Figures

    Syntax¶

    %forestplot(
     data     =
   , plot     =
   , par      =
   , columns  =
   , where    =
   , estimate =
   , lower    = lcl
   , upper    = ucl
   , within   =
   , group    =
   , by       =
   , scale    = log
   , text     = yes
   , xlabel   = "Estimate (95% CI)"
   , ref      = 1
   , file     =
   , width    = 6.5in
   , height   = 4.5in
   , out      =
   , outpar   =
   , debug    = no
 )

    Parameters¶

    data=
    The input data set: a result (rows of STAT and VALUE) of a comparison called with within=, with the variables of within=. (required)
    plot=
    Draw again: the out= of an earlier %forestplot call, changed or not. It is drawn as it is, and no statistic is computed. Give it instead of data=. (optional)
    par=
    The drawing parameters of an earlier %forestplot call: its outpar=. A drawing parameter given in the call wins over its row of par=. (optional)
    columns=
    The data set of %columns: it gives the order of the groups and their colours. When not given, the groups come in the order of the data. (optional)
    where=
    The rows of the result to use: a condition in parentheses, such as where = (versus = 'Placebo'). (optional)
    estimate=
    The statistic of the estimate: a value of STAT, such as hr, or, irr, rr, rd or diff. (required)
    lower=
    The statistic of the lower limit: a value of STAT. (optional, default lcl)
    upper=
    The statistic of the upper limit: a value of STAT. (optional, default ucl)
    within=
    The factors: variables of the result separated by blanks, one per factor, in the order of the rows (within = sex agegr1). A row belongs to the first of them that has a value. (required)
    group=
    A variable with the heading of each factor. When not given, the heading is the label of the variable of within=. (optional)
    by=
    The group of a pair: a variable of the result. When the result has VERSUS, the pair is the group of by= against VERSUS. Each pair has its own colour. (optional)
    scale=
    The scale of the x axis: log (for a ratio) or linear (for a difference). (optional, default log) Accepts: log, linear.
    text=
    yes: write the estimate and its limits, as "estimate (lower, upper)", at the right under the name of the statistic, with the n when the result has a statistic n. (optional, default yes) Accepts: yes, no.
    xlabel=
    The label of the x axis: a text in quotes. (optional, default "Estimate (95% CI)")
    ref=
    The line of no difference on the x axis: one value, 1 for a ratio or 0 for a difference. (optional, default 1)
    file=
    The output file without its extension: the macro writes <file>.png (300 dpi) and <file>.rtf. (required)
    width=
    The width of the figure: a length with its unit (width = 9in). (optional, default 6.5in)
    height=
    The height of the figure: a length with its unit (height = 6in). (optional, default 4.5in)
    out=
    The name of the data set of the numbers drawn. When not given, they are not kept. (optional)
    outpar=
    The name of the data set of the drawing parameters, one row each. Give it to par= of a later call to draw the figure again. (optional)
    debug=
    yes: keep the work data sets forestplot. (optional, default no)* Accepts: yes, no.

    Result¶

    The data set of out=: one row per level and pair: FACTOR (the variable of within=), LEVEL (its value as printed), PAIR (the group of by= against VERSUS; blank without by=), KIND (estimate), X (the estimate), LOWER, UPPER and N (missing when the result has no statistic n). The data set of outpar=: one row per drawing parameter, in the order of the table: PARAMETER ($32), its name, and VALUE ($500), its value as drawn (a label in quotes). The files: <file>.png and <file>.rtf.

    Details¶

    It computes no statistic: it draws a result of %cox, %logistic, %rateratio, %lsmeans or %risk called with within=, so the figure and the table of the same result cannot differ. A result is the data set a statistics macro writes, one row per number. For the test of the treatment-by-subgroup interaction, use the %interaction_* macros. Each factor of within= has a heading row, with one row per level under it. The estimate is a marker and its confidence interval a bar; a line marks no difference. A ratio has a log axis (scale=log). With text=yes, the estimate and its limits are also written as text at the right. To draw the figure again without computing, give plot= the out= and par= the outpar= of an earlier call.

    Good to know

    Draw again: plot= takes the out= of an earlier %forestplot call, changed or not, and draws it as it is, with no statistic computed: the factors, levels and pairs in the order of its rows, each factor under the heading of its name. par= takes the outpar= of that call and gives the drawing parameters: columns, estimate (with plot= only for the name over the text column), scale, text, xlabel, ref, file, width, height. These change the picture, not the numbers. The other parameters compute; with plot= the log has a NOTE for each one given, as it is not used. A drawing parameter given in the call wins over its row of par=, and the row wins over the default of the table.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read hr_sub (made by the example of %stack), t14_2_1_cols (made by the example of %columns). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %tte, %describe, %anova, %freq, %chisq, %cox, %stack, %columns, in this order. Then the examples of this page run as shown.

    /* from the example of %tte */
* Makes TTDE. Log NOTE: 2 subject(s) with no event and no censoring date: no record (no TRTEDT).;
%tte(
     subjects      = adsl
   , events        = adae
   , event         = trtemfl = 'Y' AND aebodsys = 'SKIN AND SUBCUTANEOUS TISSUE DISORDERS'
   , date          = astdt
   , start         = trtsdt
   , censor_date   = trtedt
   , seq           = aeseq
   , censor_desc   = "End of treatment"
   , censor_source = "ADSL"
   , event_desc    = aedecod
   , source        = "ADAE"
   , paramcd       = "TTDE"
   , out           = adttde
 )
/* from the example of %describe */
* Summarizes age in each group and in the Total: n, mean, SD, median, minimum and maximum.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a
   , total = yes
   , label = "Age (years)"
   , out   = age_describe
 )
/* from the example of %anova */
* Tests age across the three groups: one row, the p value of the F test.;
%anova(
     data  = adsl
   , var   = age
   , by    = trt01a
   , label = "Age (years)"
   , out   = age_anova
 )
/* from the example of %freq */
* Counts each sex in each group and in the Total: n and the percent of the subjects of the group.;
%freq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , total = yes
   , label = "Sex"
   , out   = sex_freq
 )
/* from the example of %chisq */
* Tests sex across the groups: one row, the p value of the chi square test.;
%chisq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , label = "Sex"
   , out   = sex_chisq
 )
/* from the example of %cox */
* Gives the hazard ratio against Placebo for each sex: the rows carry SEX, for a forest plot.;
%cox(
     data   = adttde
   , var    = aval
   , by     = trt01a
   , within = sex
   , pairs  = "Xanomeline High Dose" "Placebo"
            # "Xanomeline Low Dose"  "Placebo"
   , out    = hr_sex
 )
* Gives the hazard ratio against Placebo for each age group.;
%cox(
     data   = adttde
   , var    = aval
   , by     = trt01a
   , within = agegr1
   , pairs  = "Xanomeline High Dose" "Placebo"
            # "Xanomeline Low Dose"  "Placebo"
   , out    = hr_age
 )
/* from the example of %stack */
* Stacks four results in the order of the table: RESULT and ORD tell where each row came from.;
%stack(age_describe age_anova sex_freq sex_chisq, out=t14_2_1)
* Stacks the hazard ratios by sex and by age group, for one forest plot.;
%stack(hr_sex hr_age, out=hr_sub)
/* from the example of %columns */
* Makes the four columns with their N from adsl, the Total last, in the order of TRT01AN.;
%columns(
     data  = t14_2_1
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , total = yes
   , out   = t14_2_1_cols
 )

    Draws the hazard ratios of each subgroup on a log scale, with the reference line at 1.

    %forestplot(
     data     = hr_sub
   , columns  = t14_2_1_cols
   , estimate = hr
   , within   = sex agegr1
   , by       = trt01a
   , scale    = log
   , ref      = 1
   , file     = &spl_out./figures/f_hr_sub
   , out      = f_hr_sub
 )

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    data=<data> has no STAT and VALUE: it is not a result give data= the out= of a comparison with within=.
    estimate=<estimate> is not a statistic (STAT) of data=<data>. give estimate= a statistic of the results (hr, or, rd).
    data= and plot= are both given give data= to compute, or plot= to draw an out= again.
    plot=<plot> does not exist give plot= an out= of %forestplot (make it first).
    plot=<plot> has no variable <variable> give plot= the shape of out=: <the variables of out=>.
    par=<par> does not exist give par= an outpar= of %forestplot (make it first).
    par=<par> has no variables PARAMETER and VALUE give par= an outpar= of %forestplot.
    par=<par> has a row of no drawing parameter (with the PARAMETER of the record) give par= rows of outpar= of %forestplot only.
