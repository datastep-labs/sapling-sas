    %table_visit¶

    Makes a table of the descriptive statistics of each variable by group, parameter and visit in one call.

    Procedure: none of its own (those of %describe, %table) · Family: Tables in one call

    Syntax¶

    %table_visit(
     data      =
   , adsl      =
   , pop       =
   , where     =
   , vars      =
   , by        =
   , param     = PARAMCD
   , visit     = AVISIT
   , keep      =
   , order     =
   , post      =
   , postwhere = (ablfl NE 'Y')
   , names     =
   , total     = no
   , format    =
   , name      =
   , show      = no
   , stats     =
   , title     =
   , footnote  =
   , file      =
   , debug     = no
 )

    Parameters¶

    data=
    The input data set: the records, with USUBJID. (required)
    adsl=
    The subjects: a data set with one row per subject. It gives the population and the N of each column, and its variables are merged onto the records by USUBJID. When not given, the N of a column is the subjects of its records. (optional)
    pop=
    The population: a condition on adsl= in parentheses, such as pop = (saffl = 'Y'). It is used only with adsl=. (optional)
    where=
    The records to use: a condition in parentheses, such as where = (trtemfl = 'Y'). (optional)
    vars=
    The numeric variables to describe, separated by blanks: one block each, such as vars = aval chg. (required)
    by=
    The groups of the columns: one character variable, such as by = trt01a. (required)
    param=
    The variable of the parameter: one variable. (optional, default PARAMCD)
    visit=
    The variable of the visit: one variable. (optional, default AVISIT)
    keep=
    Other variables to keep for the names and the order of the rows, separated by blanks (keep= of %describe), such as keep = param paramn avisitn. (optional)
    order=
    The numeric twin of by=, such as order = trt01an: it gives the order of the columns. (optional)
    post=
    The variables of vars= whose block uses only the records of postwhere=, separated by blanks, such as post = chg. (optional)
    postwhere=
    The records after baseline: a condition in parentheses. (optional, default (ablfl NE 'Y'))
    names=
    The labels of the blocks: pairs variable="text", separated by blanks, such as names = chg="Change from baseline". A block without a pair has the label of its variable, or its name. (optional)
    total=
    yes: add the column Total, all groups together. (optional, default no) Accepts: yes, no.
    format=
    The labels of the categories: pairs of a variable and a format, as in a FORMAT statement (format = sex $sexf. race $racef.), as format= of %layout. (optional)
    name=
    The name of the table: the first part of the names of its data sets, such as name = t14_3_01. When not given, the last part of file= is used; without file=, name= is required. (optional)
    show=
    yes: write the long program to the log. A file path, without quotes: write the long program to that file. In both cases the macro runs it. (optional, default no)
    stats=
    The statistics, each name with its pattern, separated by blanks (stats= of %describe). (optional)
    title=
    The titles of the table: one text in quotes per line (TITLE1, TITLE2 ...). They hold for this table only. When not given, the TITLE statements in force in the program are used. (optional)
    footnote=
    The footnotes of the table: one text in quotes per line (FOOTNOTE1, FOOTNOTE2 ...). They hold for this table only. When not given, the FOOTNOTE statements in force in the program are used. (optional)
    file=
    The output file without its extension: the macro writes <file>.rtf, <file>.lst and the numbers file. When not given, nothing is printed. (optional)
    debug=
    yes: keep the work data sets of the macros that the long program calls. (optional, default no) Accepts: yes, no.

    Result¶

    The data sets: <name>_<variable> (the result of each variable), <name> (the stacked results), <name>_cols, <name>_display, <name>_pop (with adsl=) and <name>_rec (with adsl= or where=). The files: <file>.rtf, <file>.lst and the numbers file (only with file=). The global macro variable: <name>_print. With show=: the long program, in the log or in a file.

    Details¶

    Use it for vital signs or laboratory values over the visits; use %table_summary for one row per subject, and %table_model for a model at one visit. A block is the rows of one variable of vars= in the table: one %describe of the records with by= the group, the parameter and the visit. The long program is the program the macro writes and runs: the population, the records, one %describe per variable, %stack and %table, the calls a person would write by hand. The macro computes nothing itself. These data sets stay in WORK, for a change and a second print:

    • <name>_<variable>: the result of each variable, one row per number (the result shape)
    • <name>: the stacked results
    • <name>_cols: the columns (%columns)
    • <name>_display: the display data set, one row per printed line (%layout)

    The global macro variable <name>_print keeps the call of %print: change <name>_display, then print again with %print(&<name>_print.).

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. All examples of the reference run as one program: examples/reference.sas.

    Makes the table of the value at each visit and of its change after baseline.

    %table_visit(
     data  = adam.advs
   , adsl  = adam.adsl
   , pop   = (saffl = 'Y')
   , where = (paramcd = 'SYSBP' AND (ablfl = 'Y' OR anl01fl = 'Y'))
   , vars  = aval chg
   , by    = trt01a
   , keep  = param paramn avisitn
   , order = trt01an
   , post  = chg
   , title = "Table 14.7.1 Systolic blood pressure by visit"
   , file  = &spl_out./tlf/t14_7_1
 )

    Names the blocks, asks for Q1 and Q3 and adds a Total column.

    %table_visit(
     data  = advs
   , adsl  = adsl
   , where = (paramcd = 'DIABP' AND (ablfl = 'Y' OR anl01fl = 'Y') AND avisitn IN (0 12 24))
   , vars  = aval chg
   , by    = trt01a
   , keep  = param paramn avisitn
   , order = trt01an
   , post  = chg
   , names = aval="Value" chg="Change from baseline"
   , total = yes
   , stats = n mean sd median q1 q3 min max
   , title = "Table 14.7.2 Diastolic blood pressure at Week 12 and Week 24"
   , file  = &spl_out./tlf/t14_7_2
 )

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    name= is required when file= is blank. give name=<the name of the table>, as t14_5_2.
    adsl=<ds> does not exist. give adsl= the data set of the subjects.

    See also¶

    Tables in one call: %table, %table_summary, %table_ae, %table_shift, %table_response, %table_model, %table_tte.

    Named on this page: %describe, %layout, %stack, %columns, %print.

    Proof¶

    Checked against its long program, written out by hand: the same display data set (PROC COMPARE), on a made-up study; ran on SAS 9.4 M9, 2026-11-13.

    The examples of this page ran on SAS 9.4 M9 on 2026-11-27, with a log free of ERROR and WARNING.
