    %cox¶

    Returns the hazard ratio of pairs of groups from a Cox proportional hazards model, with its confidence limits and p-value.

    Procedure: PROC PHREG (LSMEANS); PROC LIFETEST for pvalue=logrank · Family: Time to an event

    Syntax¶

    %cox(
     data   =
   , where  =
   , var    =
   , by     =
   , cnsr   = CNSR
   , within =
   , covars =
   , class  =
   , strata =
   , pairs  = all
   , order  =
   , ties   = efron
   , pvalue = wald
   , level  = 0.95
   , stats  = hr="XX.XX" lcl="XX.XX" ucl="XX.XX" pval="X.XXX"
   , label  =
   , out    =
   , debug  = no
 )

    Parameters¶

    data=
    The input data set: one record per subject, with USUBJID, the time and the censoring variable. (required)
    where=
    The records to use: a condition in parentheses, such as where = (paramcd = 'TTDE'). (optional)
    var=
    The time: one numeric variable, such as aval. (required)
    by=
    The groups of the model: one character variable. (required)
    cnsr=
    The censoring variable: one numeric variable, 0 for an event and a positive value for a censoring (the ADaM CNSR: 1, 2 ... name the reason). A missing or negative value on a record used stops the macro with an ERROR. (optional, default CNSR)
    within=
    One model in each group of these variables, separated by blanks (within = sex for the levels of a subgroup). A record with a missing value of one of them is not used. (optional)
    covars=
    The numeric covariates of the model, separated by blanks (covars = age). (optional)
    class=
    The class factors of the model, separated by blanks (class = sitegr1). (optional)
    strata=
    The strata of the model, separated by blanks (strata = sitegr1). When not given, the model has no strata. (optional)
    pairs=
    The pairs of groups to compare. all: each later group against each earlier one, in the order of order= (or of the values). Or a list of pairs separated by #: the group first, then the group it is compared with, each value in quotes ("Drug" "Placebo" # "High" "Low"). (optional, default all)
    order=
    The order of the groups: one numeric variable with one value per group (order = trt01pn). (optional)
    ties=
    The method for tied times: efron, breslow, or exact (TIES=DISCRETE of PROC PHREG, which coxph of R calls exact). discrete is accepted as another name of exact. (optional, default efron) Accepts: efron, breslow, exact, discrete.
    pvalue=
    The p-value of each pair: wald (the Wald test of the pair in the model) or logrank (the log-rank test of the two groups of the pair, in the strata). logrank is not possible with within=. (optional, default wald) Accepts: wald, logrank.
    level=
    The confidence level: a number between 0 and 1. (optional, default 0.95)
    stats=
    The statistics, in the order of the rows: each name with its pattern of the printed number, separated by blanks. The names are hr, lcl, ucl and pval. A name without a pattern takes its default pattern: see the table of default patterns. (optional, default hr="XX.XX" lcl="XX.XX" ucl="XX.XX" pval="X.XXX")
    label=
    The label of the block in the table: a text in quotes. A block is the rows of one call in the table. (optional)
    out=
    The name of the result data set. (required)
    debug=
    yes: keep the work data sets cox. (optional, default no)* Accepts: yes, no.

    Result¶

    The data set of out=: the result shape, one row per pair and statistic: the BY variable (the group), VERSUS (the group it is compared with), the variables of within=, GROUPS, BLOCK, STAT, VALUE and TEXT. hr is the hazard of the group over the hazard of VERSUS (a hazard ratio below 1: fewer events in the group, as its hazard is lower), lcl and ucl its confidence limits, pval its p-value. With pairs=all the group is the later one in the order of order=. GROUPS is the name of the BY variable, VERSUS and the names of within=.

    Details¶

    Use %logrank for the test of all groups together without a model, and %interaction_phreg for the test of a treatment-by-subgroup interaction. The model has the groups, the covariates and the class factors. With strata=, each combination of the values of the strata variables is a stratum with its own baseline hazard. All pairs come from one fit: hr is the hazard ratio, lcl and ucl are its Wald confidence limits, and pval is the Wald p-value of the pair. With pvalue=logrank, pval is the log-rank test of the two groups of the pair, in the same strata (PROC LIFETEST); the hazard ratio and its limits stay those of the model. The model uses one record per subject (in each group of within=). CNSR 0 is an event and any positive value is a censoring, as in ADaM, where the value names the reason of the censoring: a CNSR of 2 is censored as 1 is. A record used with a missing or negative CNSR stops the macro with an ERROR.

    Good to know

    The ties of the library are Efron's, as in coxph of R; PROC PHREG by itself uses Breslow's.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read adttde (made by the example of %tte). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %tte, in this order. Then the examples of this page run as shown.

    /* from the example of %tte */
* Makes TTDE. Log NOTE: 2 subject(s) with no event and no censoring date: no record (no TRTEDT).;
%tte(
     subjects      = adsl
   , events        = adae
   , event         = trtemfl = 'Y' AND aebodsys = 'SKIN AND SUBCUTANEOUS TISSUE DISORDERS'
   , date          = astdt
   , start         = trtsdt
   , censor_date   = trtedt
   , seq           = aeseq
   , censor_desc   = "End of treatment"
   , censor_source = "ADSL"
   , event_desc    = aedecod
   , source        = "ADAE"
   , paramcd       = "TTDE"
   , out           = adttde
 )

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    pvalue=logrank is not made within groups (within=<within>) write pvalue=wald.
    cnsr=<cnsr> is missing or negative on <nbad> record(s) used give each record CNSR 0 (an event) or more (a censoring).

    See also¶

    Time to an event: %km, %logrank.

    Named on this page: %interaction_phreg.

    Checked against its known answer (on a small data set, the numbers worked out independently in R); ran on SAS 9.4 M9, 2026-11-12.
