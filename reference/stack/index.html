    %stack¶

    Stacks results one under another into one table, a block per result, in the order given.

    Procedure: a DATA step (SET INDSNAME=) · Family: Build a table

    Syntax¶

    %stack(
     <results>
   , out     =
 )

    Parameters¶

    results (the first value, without a keyword)
    The results to stack: data set names separated by blanks, in the order of the blocks. Give them first, without a keyword (%stack(a b, out=t)), or as results= (%stack(results=a b, out=t)); a message names them results=. (required)
    out=
    The name of the stacked table. (required)

    Result¶

    The data set of out=: all rows of the results in the result shape, with two more variables: RESULT, the name of the result that the row comes from, and ORD, the place of that result in the list (1, 2, ...). A result with no row keeps its number. A result named twice has the place of its first name. %layout lays out the blocks in the order of ORD.

    Details¶

    Call it before %columns, %ard and %layout, which read the stacked table. A result is the data set that a statistics macro writes (%describe, %freq, a test or a model): one row per number. Every result has the same variables, the result shape:

    • the group variables, as in the data (TRT01A, AEDECOD, AVISIT ...); VERSUS: the group that a difference is made with
    • GROUPS: the names of the group variables, in their order
    • BLOCK: the label of the block
    • STAT: the name of the statistic (n, pct, mean, pval ...)
    • VALUE: the number
    • TEXT: the number as printed

    A block is the rows of one call in the table: the rows of one result, under its label. A DATA step of your own can write a result in the same shape. Each variable gets the longest length it has in the results, so that no text is cut.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read age_describe (made by the example of %describe), age_anova (made by the example of %anova), sex_freq (made by the example of %freq), sex_chisq (made by the example of %chisq), hr_sex (made by the example of %cox), hr_age (made by the example of %cox), age_sex (made by the example of %describe), agegr_sex (made by the example of %freq). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %tte, %describe, %anova, %freq, %chisq, %cox, in this order. Then the examples of this page run as shown.

    /* from the example of %tte */
* Makes TTDE. Log NOTE: 2 subject(s) with no event and no censoring date: no record (no TRTEDT).;
%tte(
     subjects      = adsl
   , events        = adae
   , event         = trtemfl = 'Y' AND aebodsys = 'SKIN AND SUBCUTANEOUS TISSUE DISORDERS'
   , date          = astdt
   , start         = trtsdt
   , censor_date   = trtedt
   , seq           = aeseq
   , censor_desc   = "End of treatment"
   , censor_source = "ADSL"
   , event_desc    = aedecod
   , source        = "ADAE"
   , paramcd       = "TTDE"
   , out           = adttde
 )
/* from the example of %describe */
* Summarizes age in each group and in the Total: n, mean, SD, median, minimum and maximum.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a
   , total = yes
   , label = "Age (years)"
   , out   = age_describe
 )
* Adds sex as a second BY variable: the rows of each group and sex, for a page per sex.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a sex
   , total = yes
   , label = "Age (years)"
   , out   = age_sex
 )
/* from the example of %anova */
* Tests age across the three groups: one row, the p value of the F test.;
%anova(
     data  = adsl
   , var   = age
   , by    = trt01a
   , label = "Age (years)"
   , out   = age_anova
 )
/* from the example of %freq */
* Counts each sex in each group and in the Total: n and the percent of the subjects of the group.;
%freq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , total = yes
   , label = "Sex"
   , out   = sex_freq
 )
* Adds sex as a second BY variable: the age groups of each group and sex, for a page per sex.;
%freq(
     data  = adsl
   , var   = agegr1
   , by    = trt01a sex
   , total = yes
   , label = "Age group"
   , out   = agegr_sex
 )
/* from the example of %chisq */
* Tests sex across the groups: one row, the p value of the chi square test.;
%chisq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , label = "Sex"
   , out   = sex_chisq
 )
/* from the example of %cox */
* Gives the hazard ratio against Placebo for each sex: the rows carry SEX, for a forest plot.;
%cox(
     data   = adttde
   , var    = aval
   , by     = trt01a
   , within = sex
   , pairs  = "Xanomeline High Dose" "Placebo"
            # "Xanomeline Low Dose"  "Placebo"
   , out    = hr_sex
 )
* Gives the hazard ratio against Placebo for each age group.;
%cox(
     data   = adttde
   , var    = aval
   , by     = trt01a
   , within = agegr1
   , pairs  = "Xanomeline High Dose" "Placebo"
            # "Xanomeline Low Dose"  "Placebo"
   , out    = hr_age
 )

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    results=<ds> does not exist give results= results that exist (make them first).
