    %ard¶

    Writes every number of a table to a CSV file, the numbers file.

    Procedure: DATA steps (FILE, PUT) · Family: Build a table

    Syntax¶

    %ard(
     data    =
   , columns =
   , file    =
 )

    Parameters¶

    data=
    The stacked results (out= of %stack). (required)
    columns=
    The columns (out= of %columns). When given, the N of each column comes first, as the result N. (optional)
    file=
    The name of the numbers file, without its extension. When not given, it is the name of the program that %study set; without %study, file= is required. (optional)

    Result¶

    The files: <out>/ard/<file>.csv, where <out> is the output folder that %study set and <file> is in lower case. Its columns: result (the name of the result), stat (the statistic), g1_value to g5_value (the values of the group variables in the order of GROUPS of the result: the column first, then the levels of the row, such as VERSUS of a comparison), raw (the value written with BEST32.: at most 15 significant digits and at most 14 decimals, the last digit cut, not rounded, so that 664/9 is 73.7777777777777; a whole number in full; blank for a missing value) and formatted (the printed text).

    Details¶

    Use %csv for the records of a listing or the numbers of a figure. The numbers file has one line per number: the result it comes from, its statistic, the values of its groups, and the number as stored and as printed. The number as stored is the value written with the format BEST32.: at most 15 significant digits and at most 14 decimals, the digits after them cut, not rounded (664/9 is 73.7777777777777); the number as printed is the TEXT of the result. It reads the results, never the printed page, so that a second program, in SAS or R, can compare its numbers with this file.

    • With columns=, the first lines are the N of each column (the result N).
    • A number has the values of at most five groups (g1_value to g5_value), in the order of GROUPS.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read t14_2_1 (made by the example of %stack), t14_2_1_cols (made by the example of %columns). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %describe, %anova, %freq, %chisq, %stack, %columns, in this order. Then the examples of this page run as shown.

    /* from the example of %describe */
* Summarizes age in each group and in the Total: n, mean, SD, median, minimum and maximum.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a
   , total = yes
   , label = "Age (years)"
   , out   = age_describe
 )
/* from the example of %anova */
* Tests age across the three groups: one row, the p value of the F test.;
%anova(
     data  = adsl
   , var   = age
   , by    = trt01a
   , label = "Age (years)"
   , out   = age_anova
 )
/* from the example of %freq */
* Counts each sex in each group and in the Total: n and the percent of the subjects of the group.;
%freq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , total = yes
   , label = "Sex"
   , out   = sex_freq
 )
/* from the example of %chisq */
* Tests sex across the groups: one row, the p value of the chi square test.;
%chisq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , label = "Sex"
   , out   = sex_chisq
 )
/* from the example of %stack */
* Stacks four results in the order of the table: RESULT and ORD tell where each row came from.;
%stack(age_describe age_anova sex_freq sex_chisq, out=t14_2_1)
/* from the example of %columns */
* Makes the four columns with their N from adsl, the Total last, in the order of TRT01AN.;
%columns(
     data  = t14_2_1
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , total = yes
   , out   = t14_2_1_cols
 )

    Writes every number of the table and each column N to one CSV file: the raw value and the text.

    %ard(data=t14_2_1, columns=t14_2_1_cols, file=t14_2_1)

    Proof¶

    The tables of a made-up study: 759 of 759 numbers the same as those of a second program in R; ran on SAS 9.4 M9, 2026-11-12.

    The examples of this page ran on SAS 9.4 M9 on 2026-11-27, with a log free of ERROR and WARNING.

    Used in the proof against pharmaverse: t14_2_01 (R Submission Pilot 1), t14_3_01 (R Submission Pilot 1), t14_3_02 (R Submission Pilot 1), adverse_events (pharmaverse examples), demographic (pharmaverse examples). See what the proof shows.
