    %table¶

    Makes a table from the stacked results in one call: %columns, %ard, %layout and %print, in that order.

    Procedure: none of its own (those of %columns, %ard, %layout, %print) · Family: Tables in one call

    Syntax¶

    %table(
     data   =
   , n      =
   , var    =
   , order  =
   , total  = no
   , format =
   , label  =
   , rows   = 40
   , file   =
   , nodata =
   , setup  =
   , out    =
   , debug  = no
 )

    Parameters¶

    data=
    The results stacked by %stack: one data set in the result shape. (required)
    n=
    The population for the N of each column: a data set with one row per subject (n= of %columns). When not given, the columns have no N. (optional)
    var=
    The column variable of the results: one variable, such as var = trt01a. (required)
    order=
    The numeric twin of var= in the data set of n=, such as order = trt01an: it gives the order of the columns. (optional)
    total=
    yes: the results have the group Total, and it is the last column (total= of %columns). A text in quotes is another name for the Total. (optional, default no)
    format=
    The labels of the categories: pairs of a variable and a format, as in a FORMAT statement (format = sex $sexf. race $racef.), as format= of %layout. (optional)
    label=
    The labels of the columns: pairs name="text", separated by blanks (label= of %print). (optional)
    rows=
    The number of rows a page holds: %print keeps the rows of one level on one page when they fit. (optional, default 40)
    file=
    The output file without its extension: the macro writes <file>.rtf, <file>.lst and the numbers file <out>/ard/<last part of file>.csv. When not given, nothing is printed. (optional)
    nodata=
    The text printed when the table has no row: a text in quotes. (optional)
    setup=
    The name of a global macro variable that keeps the call of %print for out=. When not given, no macro variable is left. (optional)
    out=
    The name of the display data set. When not given, it is <data>_display. (optional)
    debug=
    yes: keep the work data sets of the macros that %table calls. (optional, default no) Accepts: yes, no.

    Result¶

    The data set of out=: the display data set of %layout. The data sets: <data>_cols, the columns of %columns. The files: <file>.rtf and <file>.lst of %print, and the numbers file of %ard (only with file=). The global macro variable: with setup=, the global macro variable of that name, which holds the parameters of %print for out=.

    Details¶

    Use %table when the defaults of the four steps fit; call %columns, %ard, %layout and %print one by one to change a step between them. It passes them the same parameters as the separate calls and adds no logic of its own. The display data set is the data set %layout writes: one row per printed line, one column per printed column. The numbers file is the CSV file of %ard with every number of the table; the macro writes it only with file=, because it belongs to an output. The columns <data>_cols and the display data set out= stay in WORK. With setup=, a global macro variable also keeps the call of %print for out=: change out=, then print again with %print(&<setup>.). Without file=, the macro prints nothing: change out=, then call %print(&<setup>., file=...).

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. They also read t14_2_1 (made by the example of %stack). All examples of the reference run as one program: examples/reference.sas.

    Before these examples: the calls that make their inputs

    Run examples/setup.sas, then these calls from the examples of %describe, %anova, %freq, %chisq, %stack, %columns, %ard, in this order. Then the examples of this page run as shown.

    /* from the example of %describe */
* Summarizes age in each group and in the Total: n, mean, SD, median, minimum and maximum.;
%describe(
     data  = adsl
   , var   = age
   , by    = trt01a
   , total = yes
   , label = "Age (years)"
   , out   = age_describe
 )
/* from the example of %anova */
* Tests age across the three groups: one row, the p value of the F test.;
%anova(
     data  = adsl
   , var   = age
   , by    = trt01a
   , label = "Age (years)"
   , out   = age_anova
 )
/* from the example of %freq */
* Counts each sex in each group and in the Total: n and the percent of the subjects of the group.;
%freq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , total = yes
   , label = "Sex"
   , out   = sex_freq
 )
/* from the example of %chisq */
* Tests sex across the groups: one row, the p value of the chi square test.;
%chisq(
     data  = adsl
   , var   = sex
   , by    = trt01a
   , label = "Sex"
   , out   = sex_chisq
 )
/* from the example of %stack */
* Stacks four results in the order of the table: RESULT and ORD tell where each row came from.;
%stack(age_describe age_anova sex_freq sex_chisq, out=t14_2_1)
/* from the example of %columns */
* Makes the four columns with their N from adsl, the Total last, in the order of TRT01AN.;
%columns(
     data  = t14_2_1
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , total = yes
   , out   = t14_2_1_cols
 )
/* from the example of %ard */
* Writes every number of the table and each column N to one CSV file: the raw value and the text.;
%ard(data=t14_2_1, columns=t14_2_1_cols, file=t14_2_1)

    Runs columns, ard, layout and print in one call: the same table as the long program.

    %table(
     data   = t14_2_1
   , n      = adsl
   , var    = trt01a
   , order  = trt01an
   , total  = yes
   , format = sex $sexf.
   , file   = &spl_out./tlf/t14_2_1_table
   , setup  = t14_2_1_table_print
 )

    Messages¶

    The macro gives only the messages every macro shares.

    Proof¶

    Its test cases: the same .lst and the same numbers file as the separate calls; ran on SAS 9.4 M9, 2026-11-12.

    The known answers and test cases are kept with the development of the library, not in this repository.

    The examples of this page ran on SAS 9.4 M9 on 2026-11-27, with a log free of ERROR and WARNING.
