    Reference¶

    One page per macro. Every page has the same parts in the same order: the syntax with every default, the parameters, the result, the details (when the macro has them), examples with their output, the messages, the macros of the same family, and the proof.

    Start a program¶

    Set up a program and read the data.

    Macro It makes
    %study Starts a program: sets the study, the program and the output folder, opens the ADaM library, sets the options.
    %import_xpt Copies SAS transport files (XPORT version 5, .xpt) into SAS data sets in a folder.

    Describe the data¶

    Counts, percents, descriptive statistics, rates, and the records a count needs.

    Macro It makes
    %describe Returns the descriptive statistics of a numeric variable in each group: n, mean, SD, median, minimum and maximum.
    %freq Counts the subjects in each category and group, with their percent of the subjects of the group.
    %proportion Returns the percent of subjects in each category and group, with its confidence interval by a method you name.
    %rate Returns the exposure-adjusted incidence rate of each group, with its exact Poisson confidence limits.
    %worst Keeps the records of each subject at its worst level, such as the highest severity or toxicity grade.
    %termflags Returns one record per subject and term, with a flag that says whether the subject has the term.

    Test the groups¶

    One test of the groups per call: its p-value in the result.

    Macro It makes
    %anova Returns the p-value of the F test of a one-way analysis of variance of a variable between the groups.
    %ttest Returns the difference of the means of each pair of groups, with its confidence limits and the t-test p-value.
    %wilcoxon Returns the p-value of the Wilcoxon rank-sum test of each pair of groups, with the Hodges-Lehmann shift and its limits.
    %chisq Returns the p-value of the Pearson chi-square test of the groups against the categories of a response.
    %fisher Returns the p-value of Fisher's exact test of the subjects with a record against the subjects without, between groups.
    %cmh Returns the p-value of the Cochran-Mantel-Haenszel test of the groups against the categories of a response, within strata.
    %ancova Returns the Type III p-value of one numeric term in a linear model, such as the test of a dose response (test = trt01pn): the test of one numeric term, not a comparison of the groups.
    %adjust Adds the adjusted p-values of a family of pairs of groups to a result: one row padj per pair.

    Compare groups with a model¶

    Estimates of the difference between pairs of groups, with their confidence intervals and p-values.

    Macro It makes
    %lsmeans The ANCOVA of the groups: returns the differences of the LS means of pairs of groups in a linear model, with confidence limits and p-values.
    %mmrm Returns the differences of the LS means of pairs of groups at one visit from a repeated measures mixed model.
    %logistic Returns the odds ratios of pairs of groups from a logistic regression, with their Wald confidence limits and p-values.
    %risk Returns the risk difference, relative risk or odds ratio of pairs of groups, with its confidence interval and p-value.
    %rateratio Returns the rate ratios of pairs of groups from a Poisson or negative binomial model, with confidence limits and p-values.

    Time to an event¶

    Kaplan-Meier estimates, the log-rank test, and hazard ratios.

    Macro It makes
    %km Returns the Kaplan-Meier summary of a time in each group: subjects, events, the median time and its confidence limits.
    %logrank Returns the p-value of the log-rank test that compares the time to an event between the groups.
    %cox Returns the hazard ratio of pairs of groups from a Cox proportional hazards model, with its confidence limits and p-value.

    Subgroups¶

    The test of the treatment-by-subgroup interaction, one model per call.

    Macro It makes
    %interaction_glm Returns the p-value of the treatment-by-subgroup interaction in a linear model of a continuous variable.
    %interaction_logistic Returns the p-value of the treatment-by-subgroup interaction in a logistic regression of a response.
    %interaction_genmod Returns the p-value of the treatment-by-subgroup interaction in a Poisson or negative binomial model of a count.
    %interaction_phreg Returns the p-value of the treatment-by-subgroup interaction in a Cox model of a time to an event.

    Build a table¶

    Stack the results, make the columns, keep every number, lay out the rows, print.

    Macro It makes
    %stack Stacks results one under another into one table, a block per result, in the order given.
    %columns Returns the columns of a table: one row per column, with its N and the header that shows the N.
    %ard Writes every number of a table to a CSV file, the numbers file.
    %layout Returns the display data set of a table: one row per printed line and one column per group.
    %print Prints a table or a listing with one PROC REPORT into an RTF file and a monospace listing file.
    %csv Writes the records of a listing, or the numbers of a figure, to a CSV file.

    Tables in one call¶

    A whole standard table in one call: the statistics, the columns, the numbers file and the print.

    Macro It makes
    %table Makes a table from the stacked results in one call: %columns, %ard, %layout and %print, in that order.
    %table_summary Makes a summary table of the subjects in one call, such as demographics: one block per variable.
    %table_ae Makes a table of the subjects with adverse events by system organ class and preferred term in one call.
    %table_visit Makes a table of the descriptive statistics of each variable by group, parameter and visit in one call.
    %table_shift Makes a shift table in one call: the subjects in each category at baseline against each category after baseline.
    %table_response Makes a response table in one call: the responders in each group, and the comparisons of pairs of groups.
    %table_model Makes a table of a continuous endpoint in one call: descriptive statistics, and the LS means of a model.
    %table_tte Makes a time-to-event table in one call: the Kaplan-Meier summary, the log-rank test and the hazard ratios.

    Figures¶

    One call per figure: the macro computes what it draws and keeps those numbers.

    Macro It makes
    %kmplot Draws the Kaplan-Meier curve of each group as PNG and RTF files and returns the numbers drawn.
    %forestplot Draws a forest plot of estimates in subgroups as PNG and RTF files and returns the numbers drawn.
    %meanplot Draws the mean or median of each group by visit as PNG and RTF files and returns the numbers drawn.
    %lineplot Draws lines through given values, one line per group, as PNG and RTF files and returns the numbers drawn.
    %boxplot Draws box plots of a variable in each group as PNG and RTF files and returns the numbers drawn.
    %barplot Draws bars of the percent of each category by group as PNG and RTF files and returns the numbers drawn.
    %aeplot Draws the percent and risk difference of each adverse event as PNG and RTF files and returns the numbers drawn.
    %profileplot Draws one line per subject through its values by visit as PNG and RTF files and returns the numbers drawn.
    %scatterplot Draws the values of two variables against each other as PNG and RTF files and returns the numbers drawn.

    ADaM steps¶

    The steps of an ADaM program that read other records: baselines, flags, windows, last observation carried forward.

    Macro It makes
    %merge_subject Copies variables from a data set with one row per subject to every row of that subject, matched by USUBJID.
    %pick Gives each subject the value of its first or last record in another data set, as a new variable.
    %summarize Gives each subject the sum, mean, largest or smallest value of a variable over its records in another data set.
    %summarize_groups Returns one record per group with the sum, mean, largest or smallest value of each variable over the group.
    %baseline Gives every record of a group the value of the group's baseline record, as a new variable such as BASE.
    %flag_first Flags the first or last record of each group, among the records that meet a condition, with Y.
    %flag_if_any Flags with Y every row of each subject that has a record in another data set that meets a condition.
    %windows Puts each record into its analysis window by its study day, and gives it AVISIT, AVISITN and the window variables.
    %visits Gives each record its analysis visit, AVISIT and AVISITN, from the value of its variable VISIT.
    %locf Adds last-observation-carried-forward records (DTYPE = 'LOCF') to the analysis windows in which a group has no analysed record.
    %relchange Returns new records with the change from the record before, relative to the normal range, flagged in ANRIND.
    %param_wide Returns the values of several parameters side by side: one record per group, with the variables of each parameter.
    %pool Pools small groups, such as sites, into one group: a new variable that is the group, or the pooled value.
    %tte Returns one time-to-event parameter: for each subject the date of the first event, or else of the latest censoring.

    Messages every macro shares¶

    Every macro checks its parameters before it runs. A wrong call writes two lines to the log and stops; no procedure runs. These checks are the same in every macro:

    Message Fix
    <parameter>= is required give <parameter>=<value> (see <macro>.sas).
    <parameter>=<data set> does not exist give <parameter>= a data set that exists (make it first).
    <parameter>=<value> is not a variable of <data set> give <parameter>= a variable of <data parameter>=. Where the macro has a second data parameter: give <parameter>= a variable of <data parameter>= or <other data parameter>=.
    <parameter>=<value> is not one of: <the values it accepts> give <parameter>= one of them.
