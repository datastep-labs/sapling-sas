    %merge_subject¶

    Copies variables from a data set with one row per subject to every row of that subject, matched by USUBJID.

    Procedure: PROC SORT, MERGE · Family: ADaM steps

    Syntax¶

    %merge_subject(
     data  =
   , from  =
   , vars  =
   , debug = no
 )

    Parameters¶

    data=
    The data set to change in place, such as adsl or adae. (required)
    from=
    The data set to copy from: one row per subject, with USUBJID. (required)
    vars=
    The variables to copy, separated by blanks. new=old copies the variable old under the name new (vars = trtsdt trt01a=arm). (required)
    debug=
    yes: keep the work data sets merge_subject. (optional, default no)* Accepts: yes, no.

    Result¶

    The data sets: data=, changed in place: the variables of vars= added to every row, with the values of the subject in from=. A subject not in from= gets missing values.

    Details¶

    Use %pick when the other data set has more rows per subject and one of them gives the value. The rows of data= keep their order. A subject that from= does not have gets missing values. The macro stops with an ERROR when from= has two rows of one subject, or when a variable of vars= is not in from=.

    Examples¶

    The examples run on the example data after examples/setup.sas. The output under each call is the output of that run. All examples of the reference run as one program: examples/reference.sas.

    Copies the time to event records with four variables of their own.

    DATA tt;
  SET adtte;
  KEEP usubjid paramcd aval cnsr;
RUN;

    Adds the age group, the race and the planned treatment of adsl by USUBJID, two of them renamed.

    %merge_subject(
     data = tt
   , from = adsl
   , vars = agegr1 race trtp=trt01p trtpn=trt01pn
 )

    Messages¶

    A wrong call writes the message and its fix to the log and stops. The macro also gives the messages every macro shares.

    Message Fix
    vars=<bad> is not a variable of <fromds> give vars= variables of from= (new=old to rename one).
    from=<from> has more than one row of a subject (<twice>). give from= one row per subject, or use pick.sas.

    See also¶

    ADaM steps: %pick, %summarize, %summarize_groups, %baseline, %flag_first, %flag_if_any, %windows, %visits, %locf, %relchange, %param_wide, %pool, %tte.

    Proof¶

    Checked on its test cases of the variables copied from the subjects and from a period (small made-up records): every value the same as that of the expected records; ran on SAS 9.4 M9, 2026-11-12.

    The known answers and test cases are kept with the development of the library, not in this repository.

    The examples of this page ran on SAS 9.4 M9 on 2026-11-27, with a log free of ERROR and WARNING.
