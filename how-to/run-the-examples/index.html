    Run the examples of the reference¶

    This guide shows how to run the examples of the reference pages yourself, with the same output as the pages show. Each reference page has examples, and under each call the output that call made when the examples ran on SAS.

    Before you start¶

    • Have a copy of the repository datastep-labs/sapling-sas and SAS 9.4.
    • Set the path in examples/setup.sas, as the tutorial shows.

    Why one session and one order¶

    The examples ran in one SAS session, after examples/setup.sas, one macro after the other. A later example may read a data set that an earlier example made with its out=: the example of %columns reads the table that the example of %stack made, and the example of %kmplot reads the time to an event of %tte. Each reference page says which data sets its examples read from another example, under "They also read", with a link to that example.

    So run the examples in the same session and in the order below. An example that you run alone, out of this order, may stop with an ERROR because a data set it reads does not exist yet.

    Steps¶

    1. Run the setup¶

    Submit the whole of examples/setup.sas. It loads the macros, reads the example data, calls %study, and makes the WORK data sets adsl (the safety population), adae, advs, adlb, adtte and adrs that the examples read.

    2. Run the examples in this order¶

    The program examples/reference.sas holds every example in this order: submit it after examples/setup.sas, in the same session, whole or one part after another. To run the examples of one page by hand, submit the pages before it first, in the order below: the parts in their order, and in each part the pages in the order of its list. The code of a page is all its blocks, top to bottom.

    Read the data and start the program¶

    %tte comes this early because its result, adttde, is the time to an event that %km, %logrank, %cox, %kmplot and %table_tte read.

    1. %import_xpt
    2. %study
    3. %tte

    Statistics¶

    Each statistics macro writes a result. %adjust reads the result of %lsmeans.

    1. %describe
    2. %anova
    3. %freq
    4. %chisq
    5. %worst
    6. %termflags
    7. %fisher
    8. %cmh
    9. %proportion
    10. %risk
    11. %logistic
    12. %rate
    13. %rateratio
    14. %ancova
    15. %lsmeans
    16. %adjust
    17. %mmrm
    18. %ttest
    19. %wilcoxon
    20. %interaction_glm
    21. %interaction_logistic
    22. %interaction_genmod
    23. %km
    24. %logrank
    25. %cox
    26. %interaction_phreg

    Build a table¶

    %stack stacks the results of %describe, %anova, %freq and %chisq; %columns, %ard, %layout and %print then work on that table, each on what the call before it made.

    1. %stack
    2. %columns
    3. %ard
    4. %layout
    5. %print
    6. %table
    7. %csv

    Figures¶

    The figures take their order and their colors from the columns of %columns. %lineplot draws the numbers that %meanplot kept.

    1. %kmplot
    2. %forestplot
    3. %meanplot
    4. %lineplot
    5. %boxplot
    6. %barplot
    7. %aeplot
    8. %profileplot
    9. %scatterplot

    Tables in one call¶

    Each one-call table reads the data sets of setup.sas; %table_tte also reads adttde of %tte.

    1. %table_summary
    2. %table_ae
    3. %table_visit
    4. %table_model
    5. %table_response
    6. %table_tte
    7. %table_shift

    ADaM steps¶

    Each step of an ADaM program changes a data set in place. Its example first copies the records it needs into a data set of its own (vs, lb, sl or tt), so advs, adlb, adsl and adtte stay as setup.sas made them.

    1. %merge_subject
    2. %pick
    3. %summarize
    4. %flag_if_any
    5. %pool
    6. %param_wide
    7. %summarize_groups
    8. %visits
    9. %windows
    10. %locf
    11. %baseline
    12. %flag_first
    13. %relchange

    3. Compare with the pages¶

    The output under each call on a reference page is the output of this run: the first rows of each data set of out=, the first lines of each .lst and CSV file, and each figure. The tables, listings and figures are in the output folder examples/out (&spl_out.), in its folders tlf, listings, figures and ard.
