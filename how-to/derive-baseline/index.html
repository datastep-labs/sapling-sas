    Derive analysis visits, the baseline and the change from baseline¶

    This guide shows how to derive the analysis variables of a BDS data set such as ADVS from its collected records: the analysis visit of each record by its study day, the baseline flag, one analysis record per visit, the baseline value and the change from baseline.

    Before you start¶

    • Submit examples/setup.sas, or start your own program as Use the macros in your own program shows.
    • Have the records with the value (aval) and the study day (ady), one row per measurement. The guide starts from the blood pressure records of advs and keeps only the collected variables.
    • Have the visit windows and the baseline rule of the plan. The guide uses: baseline is the last value on or before day 1; Week 4, Week 12 and Week 24 are windows around their target days.
    DATA vs;
  SET advs;
  WHERE paramcd IN ('SYSBP' 'DIABP');
  KEEP usubjid trt01a paramcd param adt ady aval vsseq;
RUN;

    Steps¶

    1. Put each record in its analysis window¶

    Call %windows with one window per analysis visit, # between the windows. A window is its number (avisitn), its name, its first day, its last day, its target day and its range as printed. A period is a limit that is open:

    %windows(
     data    = vs
   , windows = 0  "Baseline" .   1   1   "<=1"
             # 4  "Week 4"   2   42  28  "2-42"
             # 12 "Week 12"  43  126 84  "43-126"
             # 24 "Week 24"  127 210 168 "127-210"
   , day     = ady
 )

    %windows changes vs in place. It adds avisit, avisitn, the limits of the window and awtdiff, the distance of the record from the target day. A record in no window keeps them missing.

    2. Flag the baseline record¶

    Call %flag_first on the records that can be the baseline, and choose the last one by the study day:

    %flag_first(
     data  = vs
   , where = (ady <= 1 AND NOT MISSING(aval))
   , by    = usubjid paramcd
   , order = ady vsseq
   , which = last
   , new   = ablfl
 )

    3. Flag one analysis record per visit¶

    Call %flag_first again, by visit. The record nearest to the target day is chosen first. On a tie, the earlier day wins, then the earlier record:

    %flag_first(
     data  = vs
   , where = (NOT MISSING(avisitn) AND NOT MISSING(aval))
   , by    = usubjid paramcd avisitn
   , order = awtdiff ady vsseq
   , new   = anl01fl
 )

    4. Give every record its baseline value¶

    Call %baseline. It copies aval of the record with ablfl = 'Y' to every record of the subject and parameter:

    %baseline(data=vs, value=aval, by=usubjid paramcd, new=base)

    5. Compute the change from baseline¶

    Compute the change in a DATA step, after the baseline visit only:

    DATA vs;
  SET vs;
  IF avisitn > 0 AND NOT MISSING(base) THEN chg = aval - base;
RUN;
