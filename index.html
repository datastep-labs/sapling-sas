    Sapling SAS macros¶

    SAS macros for the tables, listings and figures of clinical trials. A program that uses them reads like the table it makes. Every number the table prints is also written, with its full value, to a numbers file that a second program can check.

    Proven against pharmaverse

    On six published outputs of the R Consortium R Submission Pilot 1 and the pharmaverse examples, 2,181 of 2,196 numbers are the same in SAS. 14 more differ for a known reason that the check reproduces from the SAS numbers; 1 is a statistic no macro computes. What the proof shows

    A table of age and sex by treatment, from the example data:

    %describe(data=adsl, var=age, by=trt01a, total=yes, label="Age (years)", out=t_age)
%freq(data=adsl, var=sex, by=trt01a, total=yes, label="Sex", out=t_sex)
%stack(t_age t_sex, out=t14_2_01)

TITLE1 "Table 14-2.01 Age and sex";
%table(
     data  = t14_2_01
   , n     = adsl
   , var   = trt01a
   , order = trt01an
   , total = yes
   , file  = &spl_out./tlf/t14_2_01
 )
